    📱 Panduan Memasang Hasil Terjemahan ke Warband Android
    1. Unduh file CSV yang sudah selesai diterjemahkan (misalnya dialogs.csv, game_strings.csv, dll.).
    2. Buka ZArchiver, lalu masuk ke folder mod Anda di: /Penyimpanan Internal/mnb/Modules/Dynasties_of_Calradia/languages/.
    3. Buat folder baru bernama id (atau salin isi folder en ke dalam folder id).
    4. Tempel dan timpa file CSV hasil terjemahan ke dalam folder languages/id/ tersebut.
    5. Buka MnBTool atau pengaturan bahasa di dalam game dan pilih bahasa Indonesian (id).
